# Optimizing Conditional Value-at-Risk in finite Markov Decision Processes: Theory, Algorithm and Implementation

Python implementation and numerical experiments that accompany my bachelor's thesis about risk-sensitive Markov Decision Processes. 

## Contents

- `bachelor_thesis_code.ipynb`: Main Jupyter Notebook containing the implementation of the algorithm from the work and numerical experiments with this algorithm.
- `requirements.txt`: Required Python packages.

## Manual

Install the Python packages that are required by executing

  pip install -r requirements.txt

and then run the Jupyter Notebook (from top to Botton).
